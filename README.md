## Featured Engineering & Systems Work

### [Football Manager 26 Tactical Scout & Memory Engine](https://github.com/lunizura/fm26-stat-modifier)
> **Stack:** Python 3.10+ • Win32 API (`ReadProcessMemory` / `WriteProcessMemory`) • Zstandard • CustomTkinter

A high-precision Windows desktop telemetry suite, save-database parser, and live process memory modifier targeting FM26's native `ACTUAL_PLAYER@db` C++ structs:
- **Direct Process Memory Manipulation:** Resolves dynamic memory pointers and converts display attributes (`1-20`) to the internal binary scale (`5-100` at `this + 0x15F`).
- **Save Stream Decompression:** Zstandard stream engine indexing `46,500+` players and `988,000+` name dictionary entries in `<0.15s`.
- **Tactical Telemetry GUI:** Windows 11 DWM-integrated 3-column attribute matrix editor with instant one-click preset boosting.

### [Indonesian University Admission & Selectivity Engine](https://github.com/lunizura/keketatan-univ-indonesia)
> **Stack:** Vanilla JavaScript • Open Data Architecture • GitHub Pages  
> **Live Demo:** [lunizura.github.io/keketatan-univ-indonesia](https://lunizura.github.io/keketatan-univ-indonesia/)

An interactive admissions intelligence platform and risk calibration engine covering 50 premier Indonesian universities (35 PTN & 15 PTS):
- **National Selectivity Leaderboard:** Dynamic quota distribution, applicant competition ratios, and 3-year historical trajectories.
- **Choice Risk Simulator:** Dual-track portfolio heuristic evaluating application combinations across SNBP and SNBT tracks.
- **Zero Heavy Dependencies:** Lightweight client-side engine with instantaneous bilingual localization (ID / EN).
